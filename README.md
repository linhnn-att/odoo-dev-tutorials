# Setup & Workflow Guide

## 1. Clone the repository

```bash
git clone <REPO_URL>
cd <REPO_FOLDER>
```

## 2. Create a new branch

Use your name as the branch name.

Example:
nguyen ngoc linh → linhnn

```bash
git checkout -b <branch_name>
```

## 3. Do the exercises

Create Odoo custom modules

Complete the exercises

Commit after finishing each exercise

## 4. Commit your work

```bash
git add .
git commit -m "<your_message>"
```

✅ Commit message should clearly describe what you did.
Example: "Exercise 1: create custom module structure"

## 5. Push to your branch

```bash
git push -u origin <branch_name>
```
